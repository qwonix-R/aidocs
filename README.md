# About solution
this extension allows to quickly document some code in your project using integrated copilot in VS Code
# Usage
Select a code that needs to be documented and use one of these methods:
1. **Shortcut**  
    default is <kbd>Ctrl</kbd> / <kbd>Cmd ⌘</kbd> + <kbd>Alt</kbd> + <kbd>D</kbd>  
    can be changed in settings by id ```aidocs.documentCode```
2. **Palette**  
    can be invoked using <kbd>Ctrl</kbd> / <kbd>Cmd ⌘</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd> by a title *```Generate docs```*
3. **Context menu**  
    right click on a selected text and choose *```Generate docs```* option
